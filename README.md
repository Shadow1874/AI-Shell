# AssistantAI Ollama

Локальный графический ИИ-помощник на Python и [Ollama](https://ollama.com/). Приложение отправляет запросы локальному серверу Ollama и позволяет использовать установленные на компьютере языковые модели.

## Возможности

- Локальный чат с моделями, установленными в Ollama.
- Выбор модели из списка локально доступных моделей.
- Динамическое название приложения и имя ассистента в чате по определённому разработчику выбранной модели (например, Alibaba Cloud для Qwen, DeepSeek для DeepSeek, Meta для Llama, Google для Gemma).
- Потоковый вывод ответа.
- Режим раздумья XHIGH для моделей, которые поддерживают этот режим.
- Режим помощи в программировании.
- Необязательный интернет-поиск. Без него чат работает с локальной моделью и не требует подключения к интернету после установки приложения и модели.
- Чтение PDF, DOCX, TXT, Markdown, CSV, XLSX и текстовых файлов с исходным кодом.
- Настройка размера контекста: 4K, 8K, 16K, 32K, 64K, 128K или 256K.

## Требования

- Windows 10 или Windows 11.
- Python 3.10 или новее. Рекомендуется Python 3.11.
- Установленная Ollama.
- Хотя бы одна модель, загруженная в Ollama.
- Для комфортной работы крупных моделей могут потребоваться значительные объёмы RAM и VRAM. Фактическая скорость и доступный контекст зависят от модели и оборудования.

## Установка и запуск

### 1. Установи Ollama

Скачай и установи Ollama с официального сайта: https://ollama.com/download.

Проверь, что сервер Ollama доступен. В терминале выполни:

```powershell
ollama --version
ollama list
```

Если моделей ещё нет, загрузи любую совместимую модель:

```powershell
ollama pull <имя-модели>
```

Например, можно указать тег модели, который ты обычно используешь в Ollama. Название модели в интерфейсе должно совпадать с названием из `ollama list`.

### 2. Склонируй репозиторий

```powershell
git clone https://github.com/Shadow1874/AssistantAI-Ollama.git
cd AssistantAI-Ollama
```

Либо скачай ZIP-архив репозитория и распакуй его.

### 3. Создай виртуальное окружение Python

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Если PowerShell запрещает запуск скрипта активации, можно использовать CMD:

```cmd
.venv\Scripts\activate.bat
```

### 4. Установи зависимости

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 5. Проверь установку

```powershell
python check_installation.py
```

Скрипт проверит версию Python, необходимые библиотеки, подключение к локальному API Ollama и наличие загруженных моделей.

### 6. Запусти приложение

```powershell
python main.py
```

## Использование

1. Запусти Ollama.
2. Открой AssistantAI Ollama.
3. Нажми «Обновить» рядом со списком моделей и выбери установленную модель.
4. Выбери нужные режимы и отправь сообщение.
5. Для анализа документов нажми «Добавить файлы» и выбери необходимые файлы.

#### Название ассистента и разработчик модели

Название в заголовке окна и имя ассистента в сообщениях меняются при выборе модели и показывают её предполагаемого разработчика. Например, для Qwen отображается Alibaba Cloud, для Llama — Meta, для Gemma — Google. Семейство модели и её точное имя также видны в заголовке приложения. Если модель не распознана, используется нейтральное название `Local AI Assistant`, а разработчик отмечается как неопределённый. Определение выполняется по имени модели, поскольку локальный список тегов Ollama не всегда содержит достоверные сведения об издателе.

## Размер контекста

Размер контекста задаётся в верхней панели приложения и сохраняется для текущего пользователя Windows. Конфигурация хранится в пользовательской папке настроек, а не в каталоге проекта. Большие значения могут заметно увеличить потребление RAM и VRAM. Возможности также ограничиваются самой моделью.

Пример файла настроек находится в `settings.example.json`. При необходимости скопируй его в `%APPDATA%\AssistantAI-Ollama\settings.json` (например, `C:\Users\Имя\AppData\Roaming\AssistantAI-Ollama\settings.json`). Приложение также может перенести старый `settings.json` из папки проекта в пользовательскую папку настроек.

### Интернет-поиск и автономная работа

Интернет-поиск включается отдельным флажком. Для него используется пакет `ddgs`, который устанавливается вместе с остальными зависимостями. При выключенном поиске приложение не обращается к поисковому сервису. Если поиск включён, но недоступен, приложение продолжит запрос к локальной модели без результатов поиска.

После установки Python-зависимостей, Ollama и нужной модели обычный чат может работать без подключения к интернету. Сам поиск, разумеется, требует доступа к сети.

### Поддерживаемые файлы

Поддерживаются PDF, DOCX, TXT, MD, CSV, XLSX и ряд текстовых форматов исходного кода и конфигураций. Извлечение текста из сканированных PDF без текстового слоя не выполняется: для таких документов понадобится OCR. Большие документы могут обрезаться по лимиту извлечения текста.

## Диагностика

- **Не удаётся подключиться к Ollama:** запусти приложение Ollama. При необходимости открой терминал и выполни `ollama serve`. Локальный API по умолчанию доступен по адресу `http://localhost:11434`.
- **Модель не найдена:** проверь её точное имя командой `ollama list`, затем загрузи её через `ollama pull <имя-модели>`.
- **Не найден Python-пакет:** активируй виртуальное окружение и повторно выполни `python -m pip install -r requirements.txt`.
- **Нет ответа или генерация завершается по тайм-ауту:** проверь, что выбранная модель поддерживает нужный режим, а компьютеру хватает памяти.

## Конфиденциальность

Чат и прикреплённые документы передаются локальному API Ollama на этом же компьютере. При включении интернет-поиска поисковый запрос передаётся используемому поисковому сервису. Не добавляй в запросы пароли, токены и другие секреты.
